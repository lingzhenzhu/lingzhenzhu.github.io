How to Edit

Step-by-step guide for common content updates

Method 1 — Edit directly on GitHub (Recommended)
  1. Go to your repository

    Visit github.com/lingzhenzhu/lingzhenzhu.github.io

  2. Navigate to the file you want to edit

    For example, click research → index.html

  3. Click the pencil icon ✏

    This opens the in-browser editor. Make your changes.

  4. Commit changes

    Scroll down, write a short commit message, and click "Commit changes". Your site will update in ~1 minute.

Method 2 — Clone and edit locally
# Clone the repository
git clone https://github.com/lingzhenzhu/lingzhenzhu.github.io.git
cd lingzhenzhu.github.io

# Edit files with your preferred editor
code . # VS Code

# Push changes
git add .
git commit -m "Update content"
git push origin gh-pages
