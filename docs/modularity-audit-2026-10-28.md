# 模块化编辑与后台交互审计

本轮围绕实际编辑任务验证模块化能力，并修复截图反馈中的照片墙、排版编辑器、布局、导航、图标和文案问题。改动运行于本地预览，未提交、推送或部署到线上。

结论：本轮明确提出的必做功能和已发现缺陷已完成修改，最终相关回归通过，可以进入真实后端联调阶段。该结论不等于已完成生产上线验收；可选数学公式、真机输入体验及真实 Cloudflare/GitHub 环境验证的边界在文末单独列明。

## 架构评价

最终日常草稿构建还发现首页原始 HTML 达到 14,386 字节，超出既定的 14,000 字节门槛。原因之一是构建器把共用字体样式内联到每个页面。已使用 Astro 原生构建配置将样式输出为可跨页缓存的文件，未删减内容、改变样式或提高门槛；最终首页为 11,787 字节，gzip 后 4,686 字节。

内容约束位于共享 Zod 模型中；Teaching、Research、Gallery 是完整的数据模块，嵌套内容有稳定 ID。编辑、排序、跨页移动与复制通过共享操作函数执行，界面不再依赖旧页面的 HTML 组织方式。模块目录、专用编辑面板和共享前台渲染器职责分离；预览与公开页面使用同一渲染组件。

拖动列表、图片选择、图片字段、列表与详情焦点恢复、弹窗、笔记编辑器和可调宽分栏均为共用组件。正文编辑器按需加载，公开站轮播使用小型渐进增强脚本。没有保留旧版页面运行时或接入第三方 CMS 服务。

Request card 保留受保护路径边界，不能被移动到公开页面。这是访问控制约束，不是普通页面的模块限制。News、Medium 和 Contact links 使用全站共享内容源；跨页放置它们会显示同一内容源，项目、课程和照片墙的副本则独立编辑。

## 验证记录

检查包含类型检查、共享数据模型与模块操作单元测试、Edge 和 WebKit 的隔离浏览器回归、实际日常草稿预览。自动化测试使用独立数据库，教学和研究演示均在测试结束时恢复；不重置日常草稿。

- `pnpm check`：通过。
- `pnpm test`：10 个测试文件、48 个测试全部通过。
- 最终构建及输出审计通过：24 个公开内容页面，367 个内部链接；最大公开脚本 gzip 后 4,459 字节；私有文件隔离、内部链接与样式预算检查通过。
- 字体样式改为外部缓存文件后，额外复跑页面导航与标题位置、无障碍偏好保持与重置、手机及 4K 布局，Edge 和 WebKit 共 6 项全部通过。
- 最终受影响范围的浏览器回归：Edge 38 项、WebKit 38 项，共 76 项全部通过。覆盖课程与研究项目的完整操作、照片墙、跨页模块、隐藏页面、文字格式往返、调宽、导航、上传竞争、保存失败恢复、并发写入和发布边界。
- 补充检查：两个引擎的 Admin 主流程无障碍检查，以及文章列表/响应式按钮截图回归，共 4 项通过；其中文章列表两项是为保存截图而复跑，不作为额外独立功能数量。
- 响应式按钮实际检查宽度为 1440、700、390、320px。带文字的动作在 700px 及以下隐藏辅助图标；菜单等纯图标控件仍可识别，页面无横向溢出。
- 最终本地快照为修订 39：Teaching 与 Research 的模块均与演示前基线一致；Media 为照片墙与 Podcast，Blog 为 Medium，Past 保留文章列表且隐藏主导航。快照只读导出，日常草稿未被覆盖。

## 交互依据

侧边栏采用明确的内容分组、统一图标与最多两层可见层级，支持隐藏以扩大编辑空间。页面内部的详情、集合与预览保持稳定关系。分栏设置最小宽度并支持拖动，窄屏优先保留正文空间。这些实现参考 Apple 的 [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars) 与 [Split views](https://developer.apple.com/design/human-interface-guidelines/split-views) 指南。

文字编辑器参考用户提供的锤子便签截图：暖色顶栏、纸张横线、RTF 与 Markdown 徽标、格式选择弹层和分组工具栏。所有界面操作仍使用英文，图标配备名称和状态。外观一致与自动化通过不能替代真实用户的易用性评价，后续应继续依据实际编辑反馈调整。

## 后端联调边界

本轮保持 `/admin/` 与 Cloudflare Access 的既定部署方案。真实 Access 身份策略、D1、R2、GitHub 发布、备份恢复和 CDN 缓存仍需在实际环境联调；当前通过的是本地隔离测试和本地草稿预览。申请卡迁移仍需拿到有效的旧数据导出，不能用空数据替代已有余额与记录。

Markdown 集成使用官方 Tiptap Markdown 扩展，官方仍标记为 Beta。转换已隔离在编辑器边界并添加回归；升级依赖时应重复格式往返检查。Edge 与 WebKit 的桌面及窄屏自动化不能代表所有 iOS、Android 真机与输入法行为，也不代表已完成生产环境 Lighthouse 验收。
